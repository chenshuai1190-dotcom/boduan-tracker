# 复盘：代码接入与验收

日期：2026-11-06。范围：将静态原型接入 React 正式页面、全部功能入口与旧记录读取。用户已授权云端图片配置、自定义头像及 v10.7.9.567 发布；两份独立 SQL 已应用，生产预检、执行与真实上传证据见 `review-journal-cloud-configuration.md`。本文记录发布前验收，最终部署状态以对应提交的 CI、Vercel 与任务发布结论为准。

## 入口与界面

- `App.jsx` 懒加载 `ReviewJournalPage`，按用户 ID remount。
- 交易 → 全部功能 → 记录与复盘组 → 复盘；目标中的旧双栏目改为一个复盘入口，旧组件仍为兼容测试入口保留。
- 全部按日期倒序，忽略置顶；分类内允许置顶，只显示行内图标；所有信息流不显示分类标签。
- 点击博文正文或空白区域进入独立详情页；全文、图片、股票走势、市场快照和评论附件完整展示。列表取消右下角“查看记录”，保留评论入口。图片、股票卡片和更多操作仍使用各自交互。
- 顶部返回与浏览器前后退保留列表筛选、展开状态及滚动位置；详情采用当前页面内的私有 history state，不改变 URL，不提供公开分享链接。
- 昵称只读复用 `fetchPnlShareIdentity`；头像由共享 `UserAvatar` 读取本人私有头像并回退预设，不调用创建社区资料的 ensure 流程。
- 新录入支持文字、日期、心情、表情、最多 4 个股票、市场收盘快照、最多 4 张图片。编辑保持原类型。
- 新增、编辑与恢复草稿时，从正文识别系统已知股票代码和具体公司名称，并按首次提及顺序自动关联；未知代码可用 `$` 明确指定。原手动关联不因自动识别被删除，新增自动关联只占剩余空位，满 4 只会提示。手动移除的排除意图仅保存在本地草稿，发布只保存最终股票数组，不增加数据库字段；历史博文不做批量改写。
- 手机/鼠标返回列表时聚焦无描边标题；仅键盘进入博文时恢复文章焦点，保留键盘提示，避免整条博文白框。
- 头像使用圆形裁切，裁去素材自身浅色外缘，无额外边框。

## 数据合同与上线前置

旧 `disciplines`、`review_logs` 继续保存正文，不迁移或删除原记录。`supabase/review-journal.sql` 已在用户授权后执行：

- 两表增加 `review_data` 和 `review_revision`，旧行默认空 metadata。
- 元数据保存股票、市场快照、图片路径、补记、心得记录日、日志置顶等。
- 编辑/删除带 user_id 和 revision CAS；旧版本更新同样递增 revision。
- 新建使用持久 operationId，唯一索引与内容校验保护网络结果不明后的重试。
- 私有 Storage bucket `review-journal-images`：仅本人目录可访问，JPEG/PNG/WebP，10 MB/张；展示用短期签名 URL。
- 图片只在发布时上传；无完整图片上传基础设施时明确报错。保存结果不明保留已上传引用，以便重试，不误删可能已提交的附件。
- 删除/移除附件只在对应数据库变更成功后尝试清理；存储清理失败可能留下本人私有孤立文件，正式运行需要配套清理治理。

其他环境迁移未执行时，老记录仍能读取，新富内容保存会明确提示未配置，不降级丢弃附件。当前云端已完成真实登录的上传、保存、刷新回读及签名图片预览；事务内对本人、其他身份和匿名角色做只读 RLS 断言，测试数据按用户授权清理。另有 PGlite 实际 SQL fixture 验证更新、CAS、重复迁移及写入隔离；该 fixture 不代表第二个真实账号已完成浏览器登录测试。

自定义头像入口：设置 → 社区资料 → 上传。选择原图后进行方形裁剪及缩放，压缩为 512×512；独立私有 `community-avatars` 桶上限 2 MiB，`community_profiles.avatar_path` 只保存本人文件路径，保留 `avatar_key` 兼容旧客户端。本人头像、复盘、收益分享与已授权社区参赛身份使用同一来源；失败回退预设。

## 走势与市场快照

`ReviewStockReplay` 只读取当前用户 stock_trades（非波段账本），列表卡片进入可视范围后自动查询现有鉴权股票对比 API。同账户、股票及日期范围共享在途请求，最多两路并发；离开页面取消不再需要的请求。该 API 需要两只股票，以 QQQ/SPY 作请求 companion，界面只展示选定股票。

小图和回放默认展示全部交易区间，起点保留首笔交易前 183 天（最早 2000-01-01），右端延伸至最新完成收盘日，不再截取最近 65 个交易日。回放保留本次交易、1个月、3个月，增加6个月、1年和全部；局部区间仍以所选成交日期为中心。节点以成交日期对应的拆股复权收盘为锚，原始成交价单列，休市/缺失日不挪点、不补造时分秒。复盘记录日期与有效买入节点精确同日时标红，其他买入节点保持绿色；不依据创建时间或最近交易日猜测匹配。

`SnapshotPicker` 复用现有 VIX/VIX3M、CNN Fear & Greed API。精确选已完成收盘日，缺项单独处理；选择其他来源日期需显式操作。保存值与实际来源日期冻结，阅读卡片不联网更新。

市场快照卡片保留标题处的实际来源日期和指标值，移除底部来源、“保存时快照”和记录日期差异提示。VIX / VIX3M 原始值严格大于 1 时，数值及状态使用系统红色；等于或低于 1 保持普通色。列表、独立详情、评论附件及录入预览共用同一呈现，已保存数据和分类规则不变。
