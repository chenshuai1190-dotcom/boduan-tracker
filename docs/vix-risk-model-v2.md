# VIX 风险观察模型 V2（候选规则 V1）

## 边界与审计

旧实现把近三日上穿、连续十五日倒挂和缓解窗口作为互斥阶段，事件过期会掩盖仍然存在的高风险。本次以当前水平、期限结构、风险变化、持续时间、价格行为、近期事件六维替代。规则只描述收盘时的环境，没有被证明具有投资预测能力。

生产调用位于 `VixComparisonPage.jsx`；API v2 继续返回 Cboe VIX/VIX3M 同日日线及 EODHD SPY/QQQ 复权收盘，身份缓存、请求合并、旧响应保护、图表区间及交易账户边界保持原有契约。模型增加 `schemaVersion: 2`。旧字段仅作临时兼容映射，生产 UI 不再依赖 phase 或 confirmed。

## 冻结规则（历史回放前固定）

所有比较使用原始 `vix / vix3m`，展示才舍入；不对比率进行阈值吸附。倒挂定义为 ratio >= 1。截止日期以交易日为单位，只允许 date <= cutoff 的输入参与。

| 维度 | 优先级与规则 |
| --- | --- |
| 当前风险 | EXTREME_STRESS：VIX >= 30 且 ratio >= 1；其次 HIGH_STRESS：VIX > 25 且 ratio >= 1；其次 ELEVATED：VIX > 22 或 ratio >= 1；其次 LOW_VOLATILITY：VIX < 16 且 ratio < .90；其余 NORMAL。 |
| 覆盖空档 | VIX < 16 且 .90 <= ratio < 1 归 NORMAL；这是补全定义的候选约定，不是回测得出的阈值。ELEVATED 在 VIX >= 30 时显示“波动显著升高”，并独立显示未倒挂的期限结构。 |
| 期限结构 | ratio < .90：NORMAL_TERM_STRUCTURE（明显正向结构）；.90 <= ratio < 1：NEAR_FLAT（接近平坦，尚未倒挂）；1 <= ratio < 1.10：INVERTED；ratio >= 1.10：DEEP_INVERTED。 |
| 风险变化窗口 | 至少 7 个连续完成交易日。每个交易日比较该日与 3 个交易日前的 VIX 百分比变化、ratio 绝对变化。跨缺失日不累计。 |
| RISING | 连续 2 日满足：VIX 三日涨幅 >= 10%、ratio 三日增加 >= .02；或 VIX 三日涨幅 >= 20%、ratio 三日变化 >= -.02。两日各自最新 VIX 均不低于前一日。 |
| EASING | 连续 2 日满足：VIX 三日跌幅 <= -10%、ratio 三日变化 <= -.02，且两日各自最新 VIX 低于前一日。期限结构恢复正向单独不成立。 |
| 变化确认与维持 | RISING/EASING 最少两个连续候选日才进入；没有新确认时，原方向最多保留 2 日，且三日 VIX 与 ratio 变化仍同向、当日 VIX 未反向。否则落入 HIGH_HOLD/STABLE。当前和前一日均满足 VIX > 25 或 ratio >= 1 时为 HIGH_HOLD，其余 STABLE。上穿事件作为说明证据，不豁免确认。 |
| 持续时间 | 分别计当前风险等级的连续日数、高压及以上连续日数、极端连续日数、倒挂连续日数。开头缺少前序时明确为至少 N 日；遇 provider 缺口重新计数且标为下界。ratio < 1 倒挂归零。达到 15 日增加 PROLONGED_INVERSION 标签，不决定当前风险。 |
| 价格行为窗口 | SPY、QQQ 各自至少 20 个连续交易日复权收盘，仅取截至当天最近 20 日，完全不使用 VIX、事件或另一只 ETF。 |
| NEW_LOW | 当前收盘严格低于前 19 日最低收盘；相同低点不称创新低，但重置距低点日数。 |
| RECOVERY | 距最近一次窗口最低收盘 >= 5 日，连续两日收盘各自高于当日 5 日均价，且当前收盘高于 3 日前。 |
| EARLY_STABILIZATION | 不满足上述更高优先级，距最近窗口最低收盘 >= 3 日，最新收盘高于前一日。显示“短期止跌迹象”。 |
| NO_STABILIZATION | 有足够有效价格历史但不满足以上条件。缺历史为 INSUFFICIENT_DATA；缺失/错误数据为 UNKNOWN。 |
| 近期事件 | 近 3 个连续交易日内：VIX 从 <=25 到 >25；VIX 从 <30 到 >=30；ratio 从 <1 到 >=1、从 <1.10 到 >=1.10、从 >=1 到 <1；连续倒挂第一次到达 15 日。保留发生日和经过交易日。事件过期不改变当前水平。 |

价格说明固定为：“仅表示近期未创新低且价格出现回升，不代表市场底部已经形成。”RECOVERY 同样仅描述反弹，不宣称底部或买卖确认。

## 数据质量与局部可用性

同日有效 VIX/VIX3M 足以判断当前风险和期限结构。历史不足不把已知高压改为 UNKNOWN，只使方向等依赖历史的维度不可用。`ready` 表示波动率六维中非价格部分的历史足够且最新配对有效；价格另有自己的 ready 和 reason，不得因 SPY 缺失而消除 QQQ 或当日波动率结论。`dataQuality` 分别报告 provider_missing、invalid_data、insufficient_history、stale_data 等原因，并列出缺失交易日和期间的官方休市；周末/官方休市不是 provider 缺口。连续性要求不降低。

VIX 专用日历补充 NYSE 官方特殊休市（2025-01-09、2018-12-05），所有 VIX 配对、图表和模型使用同一日历；不修改共享交易、资产或实时刷新日历。

## 验证设计与限制

开发/校准使用合成边界样本和已暴露的旧模型反例；用户要求的 2020 上半年及 2021-09-27 至 2026-09-25 已在前次审计中查看，属于历史回归样本，不能称为未触碰验证集。规则冻结后首次计算 2017-01-01 至 2019-12-31 的输出，作为额外留出验证，不按该结果调参。若后续因此调整规则，该集合即失去未触碰资格。

所有 7、3、2、10%、20%、.02、20、5、15 等窗口或变化阈值以及风险水平边界均是未经投资预测验证的经验参数。本次验证覆盖、连续性、事件与状态分离、无未来信息及语义正确性；不计算策略收益，不据此宣称择时能力。复权历史为当前供应商版本，只能证明计算的 point-in-time 截断，不能还原当年的数据修订或到达时间。
